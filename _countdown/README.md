# _countdown

A countdown timer defaulting to 45:00. Up/Down adjust by a
minute, Select starts and stops, holding Select resets to
45:00. Ready is marked by a thick underline under the minutes. Drift-free (end-timestamp based); a wakeup fires at zero
even if the app is closed. While paused, a giant light-grey pause
symbol sits behind the time. Current version: 1.4.5.
